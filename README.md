# Birthday Mission — Vivo ♡

Cute Retro Pixel Arcade birthday invitation for Vivo, made by Jenni.

## Upload to GitHub

Upload everything in this folder to the root of your GitHub repository. Keep the `assets` folder intact.

### Structure
- `index.html`
- `style.css`
- `script.js`
- `assets/vivo-jenni.jpeg`
- `assets/birthday-song.mp3`

## Music
The MP3 is bundled locally. There is no visitor upload or song replacement feature. The site attempts autoplay on page load and starts the song from the **START MISSION** interaction when browser autoplay rules block sound on initial load. The only visitor control is Play/Pause.
