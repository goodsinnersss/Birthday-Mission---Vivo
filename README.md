# Birthday Mission — Retro Arcade

Upload the contents of this folder to GitHub Pages.

## Music
The only music source is `assets/birthday-song.mp3`, bundled with the website. There is no upload feature and no song-changing feature. The player has only Play/Pause. The page attempts autoplay immediately; if a browser blocks autoplay with sound, the same song starts on the visitor's first interaction.
